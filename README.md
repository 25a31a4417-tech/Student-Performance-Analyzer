# 📊 Student Performance Analyzer

A beginner-friendly Data Science mini project built using Python, Pandas, and Matplotlib to analyze student marks and visualize academic performance.

## 🎯 Project Objective

The main objective of this project is to analyze student marks, calculate percentages, identify the class topper, and visualize subject-wise performance.

## ✨ Features

- Calculate total marks and percentages of students.
- Identify the class topper.
- Calculate subject-wise average marks.
- Check whether students pass or need improvement.
- Generate charts to visualize student performance.
- Export analyzed results to a CSV file.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Dataset

## ⚙️ Installation

**Step 1:** Install Python on your computer.

**Step 2:** Install the required libraries by running:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run the Project

Open the terminal in VS Code and execute:

```bash
python main.py
```

## 📈 Project Outputs

The program displays:
- Total number of students
- Class average percentage
- Topper's name and percentage
- Subject-wise average marks
- Individual student results

It also generates:
- `subject_averages.png`
- `percentage_distribution.png`
- `student_results.csv`

These files are saved in the `outputs` folder.
